# Goals governance and ownership

## P0 — permissions and ownership integrity

- [x] Enforce creation, edit, delete and progress permissions server-side by goal level and owner.
- [x] Restrict company goals to Admin/HR; restrict managers to their team and direct reports.
- [x] Let employees create and update only their own individual goals.
- [x] Require an owner for individual goals and validate parent-goal access.

## P1 — creation experience

- [x] Add an owner selector with role-appropriate staff choices.
- [x] Add a parent-goal selector so individual/team goals can be aligned to an outcome.
- [x] Limit scope choices in the modal to those allowed for the signed-in role.
- [x] Show an employee-friendly personal-goal creation entry point.

## P2 — measurable outcomes

- [x] Add optional target value, current value and unit fields to goals.
- [x] Calculate/display progress from the metric when it is configured, while preserving manual progress for existing goals.
- [x] Add a concise goal health signal for overdue and at-risk goals.
