Kazi Timer settings

Choose where Kazi can make time tracking easier.

Open timer after starting

Open the toolbar timer after you start work from Asana, Gmail, GitHub or Slack.

Gmail timer

Show a timer action beside the subject of an open email.

Kazi reads the subject only after you start a timer. It never reads message content, recipients, attachments or mailbox history.

Floating timer

Keep compact timer controls on selected secure sites.

    The floating timer shows only your active Kazi timer and its controls. It never reads page content, form fields, browsing history or credentials. Chrome asks before a site is added.
